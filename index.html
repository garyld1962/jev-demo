    A FIVE-MINUTE DEMO

    Make the boundary visible.

    Enter your key before sharing the screen. Run one live case to check access and connectivity. Keep this tab open.

    1. Start with the ordinary case · 60 secChoose the routine request and evaluate. Point to category, urgency, and missing evidence: three typed judgments in one API call.
    2. Change one sentence · 60 secTry an ambiguous or missing-evidence case. In live mode, invite someone to change the request. Evaluate again and inspect the probabilities.
    3. Move the policy threshold · 60 secUse the ambiguous case. Slide the routing threshold past the highest category probability. The route can change instantly with the same saved judgment. No new inference occurs.
    4. Show a hard limit · 60 secLoad the high-value case. Human approval takes precedence over model certainty. Change the approval limit to show the policy boundary explicitly.
    5. Open the contract · 60 secExpand Under the hood. Show the fixed answer choices, actual JSON, and policy trace. Jev supplies judgments; application code owns control flow.
